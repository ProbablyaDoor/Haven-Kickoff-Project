# Haven-Kickoff-Project
Example platformer game for the hit hack club program "haven"
This game is a really scuffed platformer where you are a rock and you need to reach the top of a paper tower. However, you're constantly being pursued by an evil pair of scissors that want revenge for being defeated by you 500 years ago. Does that story sound insane? Thats because it is.
